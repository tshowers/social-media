Bluesky Connect

Connect your Bluesky account

Bluesky uses an app password for third-party tools like TODD. You will create that password in Bluesky, then paste it here.

TODD needs an app password because Bluesky does not use the same one-click connection flow as LinkedIn. Your regular Bluesky password will not work here.
  1. Sign in to Bluesky
  2. Open Settings
  3. Go to Privacy and Security
  4. Select App passwords
  5. Create a new app password for TODD
  6. Copy the password
  7. Paste your Bluesky handle and app password here
